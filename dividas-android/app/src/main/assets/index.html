Lançamentos deste mês

Segurança neste aparelho

Com essa opção ligada, o app abre direto e quem tiver acesso ao aparelho pode ver os lançamentos. Você pode desligá-la para voltar a pedir o PIN. Guarde seu PIN: ele continua necessário para restaurar os backups.

Seus dados

Seus dados e backups são protegidos com seu PIN. Eles ficam neste aparelho e aparelho. Guarde o PIN e baixe backups; não há recuperação se você esquecer o código. Backups antigos, baixados antes desta proteção, continuam sem PIN.

Nova compra

O valor será incluído inteiro em cada mês, desde o primeiro mês informado. Deixe o último mês vazio para continuar. Para encerrar, preencha o último mês. Ao editar o valor, todos os meses desta repetição serão alterados; para um reajuste, encerre esta e cadastre uma nova.

O valor total será dividido entre as parcelas. Para uma compra já em andamento, informe o mês da primeira parcela.

PIX é registrado como gasto pago à vista no mês informado. Não use para quitar uma fatura já cadastrada, pois isso contaria o mesmo gasto duas vezes.
